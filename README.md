### 👋 Oi, eu sou o Gabriel

Mexo com **Linux, Android, Python, C++, containers e automação** para:

- 📦 **Portar programas** para onde eles não rodam oficialmente (ex.: apps de desktop no Android)
- 🔧 **Resolver problemas** de instalação, compilação, dependências e compatibilidade
- 🤖 **Automatizar tarefas** com scripts, navegador sem tela e agentes de IA
- 🖥️ **Emular e virtualizar** ambientes: proot, containers, outras arquiteturas
- ☁️ **Configurar servidores e cloud** para deixar as coisas rodando sozinhas

🔭 Agora: rodando o [Hermes Agent](https://github.com/NousResearch/hermes-agent) direto no celular · 🔁 Contribuindo com o projeto oficial ([PR #138739](https://github.com/NousResearch/hermes-agent/pull/138739))

#### 🐳 [docker-termux](https://github.com/Padilha-BR/docker-termux)

**Docker no Android sem root**: `pull`, `run`, `build`, `exec` e `logs` com udocker + udockerd +

<details>
<summary><b>📏 Números medidos no celular (docker-termux)</b></summary>

<br>

| Preciso de… | Uso | Custo medido |
|---|---|---|
| ler o **texto** de uma página | `webget` (HTTP nativo) | **1,7 s · ~34 MB** |
| clicar, preencher, rodar JS | `webcdp` (CDP direto, sem Selenium) | **1,9 a 2,5 s** |
| a página como **imagem/PDF** | `webprint` (Chromium nativo) | 2,8 a 5 s · **~1 GB** |
| uma ferramenta Linux que não existe no Termux | `docker run` | piso de **4 s** do proot |

A lição que mais economiza tempo: comece pelo nível 1. "Página moderna" não significa "precisa de navegador".
